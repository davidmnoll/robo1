### 4. Searched for Correct Camera Driver
- Found Yahboom workspaces at:

- ascamera kept crashing with "config file path error" or memory issues

### 5. Investigated Memory Issue
- dmesg showed: `ascamera_node, bytes: 77210517504 not enough memory` (77GB allocation!)
- This is a bug in ascamera - possibly unbounded queue when frames aren't consumed
- User clarified they have a 2-axis USB camera, NOT a depth camera
- ascamera is for Angstrong depth cameras - WRONG driver for this hardware

### 6. Checked Battery Status
- Robot was beeping - checked telemetry
- Battery voltage: 9.5V (low for 3S LiPo, should be ~12.6V when full)
- Beeping confirmed as low battery warning

### 7. Investigated USB Camera
- User confirmed camera is USB, not CSI/depth
- lsusb showed no camera initially
- dmesg revealed camera was connecting then immediately disconnecting:
  ```
  usb 3-2: Found UVC 1.00 device USB 2.0 Camera (0c45:6368)
  usb 3-2: USB disconnect, device number 5
  ```
- This happened repeatedly - hardware/power issue

### 8. Rebooted Pi
- `sudo reboot` via SSH
- After reboot, camera now detected and stable:
  ```
  Bus 003 Device 002: ID 0c45:6368 Microdia USB 2.0 Camera
  ```

## Current Status
